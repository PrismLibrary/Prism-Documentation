# Media

Media integration is host-specific. The merged 9.1 Essentials package does not currently provide public camera, video, or share-sheet contracts. The portable media work is still under review and must not be treated as installed functionality.

- [Camera](camera.md): current availability boundary and application-owned integration
- [Video](video.md): picking, recording, and playback responsibilities
- [Sharing](../applicationmodel/datatransfer/share.md): share-sheet availability and file ownership
- [File system](../io/filesystem.md): the existing application-package and app-directory APIs

Use these boundaries when selecting packages: an interface proposed in a pull request is not evidence that your authorized feed already contains it.
